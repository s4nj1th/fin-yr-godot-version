# Closed-Loop LLM PCG Dungeon Crawler

A Godot 4.3 C# procedural dungeon crawler driven by real-time player telemetry and LLM closed-loop level generation.

## 🚀 Quick Start

### Prerequisites
- **Godot Engine**: 4.3 (Mono / C# Edition)
- **.NET SDK**: 8.0+

### Running the Project
1. Open Godot Engine 4.3 (Mono) and import [`project.godot`](file:///Users/s4n/Documents/clg/sem7/project%20phase%202/fin-yr-godot-version/project.godot).
2. Build via C# solution in Godot or via terminal:
   ```bash
   dotnet build DungeonCrawler.csproj
   ```
3. Press **F5** in Godot to play.
